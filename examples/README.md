# NPI Scraper API – code examples

Examples for every NPI endpoint of the [Piloterr API](https://www.piloterr.com). Python and TypeScript examples are in the [main README](../README.md).

```bash
export PILOTERR_API_KEY="your-api-key"   # get one at https://app.piloterr.com
```

| Language | File | Run |
|---|---|---|
| cURL (Bash) | [`curl/provider.sh`](curl/provider.sh) | `bash provider.sh` |
| cURL (Bash) | [`curl/search.sh`](curl/search.sh) | `bash search.sh` |
| PHP | [`php/provider.php`](php/provider.php) | `php provider.php` |
| PHP | [`php/search.php`](php/search.php) | `php search.php` |
| C# | [`csharp/Provider.cs`](csharp/Provider.cs) | `copy to `Program.cs`, `dotnet run` |
| C# | [`csharp/Search.cs`](csharp/Search.cs) | `copy to `Program.cs`, `dotnet run` |
| Go | [`go/provider.go`](go/provider.go) | `go run provider.go` |
| Go | [`go/search.go`](go/search.go) | `go run search.go` |
| Java | [`java/ProviderExample.java`](java/ProviderExample.java) | `java ProviderExample.java` |
| Java | [`java/SearchExample.java`](java/SearchExample.java) | `java SearchExample.java` |
| Ruby | [`ruby/provider.rb`](ruby/provider.rb) | `ruby provider.rb` |
| Ruby | [`ruby/search.rb`](ruby/search.rb) | `ruby search.rb` |
| Node.js | [`nodejs/provider.mjs`](nodejs/provider.mjs) | `node provider.mjs` |
| Node.js | [`nodejs/search.mjs`](nodejs/search.mjs) | `node search.mjs` |
